# Twitch RPG Bot

Twitch RPG Bot — интерактивный бот для Twitch-канала Xhionity. Создавайте персонажа, сражайтесь с монстрами, участвуйте в PvP, торгуйте, крадите и дарите предметы, чтобы стать легендой стрима!

## Возможности

- Персонаж с **расой** (человек, эльф, орк, фурри) и **классом** (воин, маг, вор)
- Бои с монстрами (Слизень, Гоблин, Скелет, Орк, Дракон) — XP, золото, лут, масштабирование по уровню
- PvP-дуэли со ставками золота
- Экономика: чёрный рынок, продажа, оценка, дарение предметов и золота
- Механики кражи, тюрьмы, таверны, борделя
- Система HP: зелья, полный отдых (`!отдых`), восстановление после боя
- Логирование в `bot.log`, резервное копирование `players.json`
- **Локальный консольный режим** для тестирования без подключения к Twitch

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Xhionity/twitch-rpg-bot.git
   cd twitch-rpg-bot
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Создайте `.env`:
   ```env
   TOKEN=your_twitch_oauth_token
   CHANNEL=your_channel_name
   SAVE_FILE=players.json
   MODE=twitch
   ```

4. Запустите бота:
   ```bash
   python rpg_bot.py
   ```

## Локальный режим

Для тестирования без Twitch установите `MODE=local` в `.env` и запустите:

```bash
python rpg_bot.py
```

Откроется консольный REPL — все команды работают в терминале. Данные сохраняются в тот же `players.json`. Подробнее: [local.md](local.md).

## Команды

| Команда | Описание |
|---------|----------|
| `!старт` | Создать персонажа |
| `!статус [@ник]` | Характеристики (уровень, XP, золото, HP, урон) |
| `!инвентарь` | Показать предметы в инвентаре |
| `!экипировка` | Показать надетые предметы |
| `!надеть <предмет>` | Экипировать предмет |
| `!снять <слот>` | Снять предмет |
| `!использовать <предмет>` | Использовать расходник (+20 HP) |
| `!описание [предмет]` | Описание предмета |
| `!опыт` | Получить XP (кулдаун 5 мин) |
| `!бой [монстр]` | Сразиться с монстром |
| `!топ` | Топ-10 игроков по уровню |
| `!дуэль @ник [ставка]` | Вызвать на PvP-дуэль |
| `!принять` | Принять дуэль |
| `!отмена` | Отменить дуэль |
| `!пвп` | Статистика PvP (победы, поражения, винрейт) |
| `!черныйрынок` | Товары чёрного рынка (обновляются каждые 10 мин) |
| `!купить <номер>` | Купить предмет с чёрного рынка |
| `!продать <предмет>` | Продать предмет за 50% цены |
| `!оценить <предмет>` | Узнать стоимость продажи |
| `!подарить @ник <предмет \| золото N>` | Подарить предмет или золото |
| `!кража @ник <предмет>` | Украсть предмет (кулдаун 5 мин) |
| `!взятка` | Выйти из тюрьмы (50 золота) |
| `!таверна` | +10% урона на 30 мин (50 золота) |
| `!бордель` | +50% XP или -50% XP на 30 мин (100 золота) |
| `!лечиться` | Снять штраф XP (50 золота) |
| `!отдых` | Полное восстановление HP (5 золота) |
| `!раса <название>` | Выбрать расу (однократно) |
| `!класс <название>` | Выбрать класс (однократно) |

## Структура проекта

```
rpg_bot.py          — основной модуль, entry point
local_bot.py        — консольный режим (LocalBot, LocalContext, BotContext)
services/
  player_service.py — XP, уровни, HP, кулдауны, бонусы снаряжения
  combat_service.py — симуляция боёв с монстрами и PvP
  inventory_service.py — инвентарь, экипировка, расходники, дарение
utils/
  decorators.py     — @requires_character
consts/
  monsters.yml      — монстры и их характеристики
  items.yml         — предметы и цены
  item_descriptions.yml — описания предметов
  races.yml         — расы и бонусы
  classes.yml       — классы и бонусы
  black_market_items.yml — товары чёрного рынка
tests/              — pytest-тесты (194 теста)
players.json        — данные игроков
bot.log             — лог действий
```
